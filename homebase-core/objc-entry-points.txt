// ObjC export list of the ComposeApp framework, debug and release (-Xbinary=objcExportEntryPointsPath in
// homebase-core/build.gradle.kts). Only the Kotlin functions and properties listed here get ObjC bridges in the
// header Swift sees; classes stay. Exporting all 35,000+ members made the release link the slowest step of the
// iOS build; with this list LLVM compiles a 16% smaller framework (IOS_RELEASE_LINK_OOM.md).
//
// Swift calls a Kotlin function or property that is not listed: Swift fails to compile ("has no member"). Add it.
// Swift IMPLEMENTS a Kotlin interface: list every member BY NAME. Kotlin calls those members, and a missing one
// is dropped from the protocol, so Swift still compiles and the call fails at runtime;
// scripts/check-objc-entry-points.py (Lint workflow) catches that. Never ".*" on such an interface: the
// wildcard also matches the equals/hashCode/toString every interface inherits, which then become required
// protocol methods the Swift classes don't implement.
//
// Format: "<function|property|callable> <fq.name>", or "<kind> <fq.Parent>.*" for the direct members of a
// class or object. Overrides of a listed member are exported too.
